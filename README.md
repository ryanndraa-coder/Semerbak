# Semerbak Group — Kemitraan

Landing page multi-brand untuk Semerbak Coffee, Matcha Que, Es Teh, dan Sempol.

## Perubahan versi ini
- Headline dan deskripsi utama dirapikan agar lebih natural dan mudah dipindai.
- Headline section dibuat terpusat.
- Layout mobile 360–430px diprioritaskan.
- Copy mengikuti naskah Semerbak yang disediakan, bukan menyalin referensi Nice Presso.
- Menu produk tidak memiliki tombol pesan WhatsApp per produk.
- WhatsApp hanya digunakan pada form konsultasi kemitraan.
- Angka ROI/proyeksi keuntungan yang belum diberikan dihapus dan diganti placeholder investasi.
- Foto booth dan foto produk yang tersedia tetap digunakan.
